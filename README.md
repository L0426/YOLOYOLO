## 📖 关于YOLO About YOLO

YOLO（You Only Look Once）是一种先进的实时目标检测算法。它将目标检测视为回归问题，能够在单次前向传播中同时预测多个边界框和类别概率。

YOLO (You Only Look Once) is an advanced real-time object detection algorithm. It treats object detection as a regression problem and can predict multiple bounding boxes and class probabilities in a single forward pass.

- **YOLOv6** - 工业级实现 / Industrial-grade implementation

- **YOLOv8** - Ultralytics最新版 / Latest from Ultralytics
- **YOLOv9** - 可编程梯度信息 / Programmable Gradient Information
- **YOLOv10** - 实时端到端检测 / Real-time end-to-end detection
